# 设计哲学

> WORLD EXPLORER 视觉系统总纲。任何外部 UI 参考、组件库、模板不得凌驾于本文档之上。

## 一句话定位

**一个漂浮在深空中的数字地球博物馆:空间感的克制科技,编辑部的温度叙事。**

## 三种视觉体系

### SPATIAL UI(空间界面)—— 3D 场景之上
- 玻璃材质(高斯模糊 + 饱和度提升 + 1px 高光描边)、悬浮胶囊/面板、深空底色。
- 原则:少而精。同屏玻璃面板 ≤4 个;一切面板可关闭;地球永远是主角。
- 交互色 = 空间青 `--we-cyan`;几何语言 = 圆(胶囊、圆形按钮、圆点标记)。

### EDITORIAL UI(编辑界面)—— 档案与故事
- 衬线大标题(Songti SC/Georgia)+ 大字号导语 + 分隔饰线(✦)+ 图注/来源脚注。
- 交互色 = 探索金 `--we-gold`;几何语言 = 矩形与长卷(图片 16:10,正文两端对齐)。
- 诚实原则:没有真实照片时显示程序生成「星图卡」并标注 `ILLUSTRATIVE · NON-PHOTO`,不用假图充数。

### UTILITY UI(工具界面)—— 搜索/图层/我的世界
- 中性灰文字阶、小号大写字距标签(we-caps-label)、紧凑行高。
- 强调效率:搜索键盘优先(↑↓/↵/ESC),开关即见即所得。

## 色彩观

深空黑蓝为底( Void #030609 → BG #060B14),文字用高透明白阶;仅两种强调色:
- **探索金**(Editorial):标题、饰线、收藏、今日精选。
- **空间青**(Spatial):坐标、开关激活态、国家信息。
语义色(成功/警示/危险)只在状态场景出现。类型色板(8 类地点)仅用于标记与标签圆点。

## 字体观

系统字体栈,零下载:
- 无衬线:SF Pro / PingFang SC(正文、UI)
- 衬线:Songti SC / Georgia(标题、故事引导)
- 等宽:SF Mono(坐标、海拔、FPS——仪器感)

## 动效观

- 慢进场、快退场;入场用 `power3.out` 类曲线(--we-ease-out),位移 ≤36px。
- 镜头运动是「第一主角」:CUBIC_IN_OUT 的长飞行 + 面板并行展开;绝不让 UI 动画和镜头打架。
- `prefers-reduced-motion`:动画时长归零、自动旋转关闭、开场序列跳过(已实现)。

## 反面清单(出现即打回)

- 廉价渐变按钮/渐变文字;彩色大色块背景。
- 无层级的一排同尺寸卡片。
- 在组件里私写颜色/字号/圆角(必须走 tokens)。
- 超过一屏的 HUD 常驻元素。
