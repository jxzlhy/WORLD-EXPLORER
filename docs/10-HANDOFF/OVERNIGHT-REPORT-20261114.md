## 4. 技术决策(带证据等级)

1. **照片扩量管线**(Python + Commons API,白名单/断点续跑/许可过滤)替代「等待再手抓」——断点续跑在 4 次网络中断中实战验证。V
2. **章节跳转内容几何自适应**(denom < 视口×0.6 隐藏)——首版假设「内容远超两屏」被实测证伪后重设计。V/O
3. **程序化星空**替代 SkyBox 六面图——零素材、可单测、low 档可隐藏。O
4. **守门 opt-in 默认关**——自动改变用户画质需显式授权。O
