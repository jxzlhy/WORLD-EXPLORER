## 3. 技术决策(带证据等级)

1. **无 ion token 方案** [V]:本地 NASA 贴图 + Natural Earth;GIBS 免 key 兜底中低空;零密钥零付费。
2. **相机单一所有权** [V 设计]:Cesium flyTo 唯一镜头入口;用户输入即中断;GSAP 不碰相机。
3. **昼夜整层近似** [V,近似]:视点—日下点角距驱动夜灯层 alpha;逐像素混合列 V0.2。
4. **数据全静态化** [V]:前端零外部 API;仅 GIBS 一个免 key 服务,失败降级。
5. **诚实占位** [O]:无照片目的地显示程序「星图卡」并标注 ILLUSTRATIVE,不伪造真实感。
